<h2 style="font-size:27px;line-height:1.5">四、Binance KYC 怎麼做比較容易通過？</h2>

<p>KYC 最常見的問題通常不是「不能認證」，而是資料、證件照片或人臉驗證不符合要求。</p>

<h3 style="font-size:23px;line-height:1.6">1. 姓名必須和證件一致</h3>

<p>不要自行使用不同拼音、暱稱或其他人的姓名。</p>

<h3 style="font-size:23px;line-height:1.6">2. 證件必須在有效期內</h3>

<p>過期證件通常無法正常完成驗證。</p>

<h3 style="font-size:23px;line-height:1.6">3. 證件照片要清楚</h3>

<p>拍攝時注意：</p>

<ul>
<li>四個邊角完整；</li>
<li>文字清晰；</li>
<li>避免反光；</li>
<li>不要裁切；</li>
<li>不要使用經過修改的圖片；</li>
<li>不要用手遮擋證件資訊。</li>
</ul>

<h3 style="font-size:23px;line-height:1.6">4. 人臉驗證保持正常光線</h3>

<p>避免戴帽子、墨鏡或其他遮擋臉部的物品，並在光線充足的環境完成辨識。</p>

<h3 style="font-size:23px;line-height:1.6">5. 居住地區填寫真實資料</h3>

<p>不同國家與地區能使用的 Binance 產品可能不同，因此不要為了某項產品權限而填寫虛假所在地區。</p>

Binance 帳戶、身分證件、人臉驗證與後續付款帳戶最好保持本人一致。使用其他人的證件或虛假資料，可能影響後續帳戶驗證與資金操作。

<p>新手最常用的訂單類型有兩種。</p>

<h3 style="font-size:23px;line-height:1.6">市價單</h3>

<p>市價單會按照目前訂單簿中可取得的價格優先成交。</p>

<p>優點：</p>

<ul>
<li>操作直接；</li>
<li>通常成交較快；</li>
<li>不需要自己設定價格。</li>
</ul>

<p>需要注意的是，市價單可能出現滑點，所以實際成交均價不一定等於下單瞬間看到的最新價格。</p>

<h3 style="font-size:23px;line-height:1.6">限價單</h3>

<p>限價單可以自己設定願意買入 BTC 的價格。</p>

<p>例如 BTC 現價為 80,000 USDT，但只願意在 78,000 USDT 附近買入，就可以掛限價單等待市場到價。</p>

<p>限價單可以控制買入價格，但缺點是<strong>市場沒有到價時，訂單可能不會成交</strong>。</p>
